# XMM-Newton Analysis of IC 4296

This repository contains XMM-Newton data products and MeerKAT radio observations of IC 4296.

## XMM-Newton Data Reduction

A detailed write-up can be found [here](https://docs.google.com/document/d/1OmPVl7sUHeKU8uRttoPIVW9xfoxpp9EsyKTCyDouej8/edit?usp=sharing).

## X-ray Surface-Brightness Maps

The background-subtracted, exposure-corrected XMM surface-brightness maps in the 0.4–1.0 keV band are available [here](https://github.com/rz-wang/ic4296/tree/main/xmm/combined/sbmaps/sci_0.4-1.0keV).

The directory includes the original, point-source-excised, and point-source-filled (`dmfilth`) maps, along with fixed-kernel Gaussian-smoothed `dmfilth` maps.
